# Portfolio - Cinematic Opening

A cinematic opening animation with Vite.

## Structure

```
portfolio-vite/
├── index.html          # Entry HTML
├── package.json        # Dependencies
├── vite.config.js      # Vite config
├── src/
│   ├── main.js         # Entry point (imports CSS)
│   └── style.css       # All animations & styles
└── public/             # Static assets
```

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Animation Timeline

| Time | Event |
|------|-------|
| 0-5s | Text scrolls from right to left |
| 5s | White bubble explodes from period position |
| 5-6.5s | Bubble expands to fill screen |
| 7s | Main content fades in |# Portfolio
